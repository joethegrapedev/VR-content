Printable headset cards

Print at 100% scale (not “fit to page”) on A4. You get eight 90×55 mm cards — standard business-card size, so they fit a headset case pocket or common label stock.

Cut along the dashed lines and attach one to each headset or its case. Anyone who picks up that headset can scan the code and reach the install instructions.

This box does not appear when printed.
